# MediaForge v0.1.0

面向 Windows 10/11 x64 的本地媒体转换悬浮窗，Rust 实现。

- 拖放或选择图片、音频、视频，自动显示可用目标格式。
- 常见图片互转、尺寸调整；音频互转、视频转码、提取音频、视频转动态 GIF。
- 1 / 2 / 4 文件并发，独立 FFmpeg 进程，限制编解码线程数。
- 音视频暂停/继续、取消任务，保护原文件，输出重名自动编号。
- 便携包内附 FFmpeg 9.0，无需安装 Rust、FFmpeg 或运行终端命令。

下载 **MediaForge-windows-x64.zip**，完整解压后双击 **MediaForge.exe**。保留旁边的 `engines` 文件夹。`.sha256` 文件用于校验下载内容。

暂停仅保留本次运行的进度，退出程序后不能继续。图片在当前文件完成后暂停/取消。图片动画和多页图片仅取首帧/第一幅，视频转 GIF 则保留动画；更多格式与质量限制见仓库 README。

此发行包由 GitHub Actions 的 Windows runner 构建，通过格式检查、Clippy、真实媒体转换、暂停/恢复、取消/清理及解压包启动检查后发布。
